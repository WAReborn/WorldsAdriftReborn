# Contributing

The project is licensed under the terms described in [the LICENSE file](LICENSE.md).

## Guidelines

- Follow the existing code style and conventions.
- Keep changes focused and relevant.
- Document any breaking changes.
- Update comments or documentation when behavior changes.
- Avoid unrelated refactors.

## Notes

Contributors are expected to understand the scope and impact of their changes. Contributions that introduce regressions, undocumented breaking changes, or unnecessary complexity may be rejected.
